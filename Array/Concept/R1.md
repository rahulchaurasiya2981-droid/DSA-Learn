Array 
-------
- collection of similar items (same DT) stored in contiguous memory locations.
- this item is accessed by using the index.


Static array
------------
- It allocates memory at compile time and it's size is fixed 

Dynamic array 
--------------
- allocates memory at runtime (shrink & grow automatically )


| Feature           | Static Array                    | Dynamic Array                          |
| ----------------- | ------------------------------- | -------------------------------------- |
| Size              | Fixed (defined at declaration)  | Flexible (can grow/shrink)             |
| Memory Allocation | Allocated once                  | Reallocated during resize              |
| Flexibility       | Not flexible ❌                  | Highly flexible ✅                   |
| Performance       | Faster (no resizing overhead) ⚡ | Slightly slower (resizing cost)       |
| Memory Usage      | Can waste memory                | Efficient (uses as needed)             |
| Implementation    | Simple                          | Complex (resize logic involved)        |
| Examples          | C arrays (`int arr[10]`)        | JS `[]`, Java `ArrayList`, Python list |
